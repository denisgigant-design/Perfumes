# Dennis’s Shop — corrected five-bottle showroom

Static GitHub Pages release. Upload all files into the repository root; there are no asset folders or build steps.

- Desktop: scroll wheel/trackpad moves between the gallery and five discrete bottle checkpoints; clicking a bottle jumps straight to its checkpoint.
- Mobile: no page scrolling or swipe navigation; tap a bottle to zoom into its niche and tap **All Fragrances** to return to the gallery.
- Background: the original rock-wall photographs remain visible as DOM images behind the transparent WebGL bottle layer. No opaque WebGL background plane.
- Models: four original GLBs unchanged. The fifth blue-and-gold product remains a static transparent PNG.
- Fallback: included bottle PNGs for browsers without WebGL.
- Basket: client-side demonstration; payment is not connected.

Only files required by this version are included. License for Three.js is retained.
